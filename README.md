# WiFi FTP

One-screen Android app: share full storage / one folder / one file to your PC over local Wi-Fi (FTP, port 2121).

## Get the APK (no Android Studio needed)
1. Create a free GitHub account, make a new **private** repo, and upload everything in this folder (keep the `.github` folder).
2. Open the repo's **Actions** tab -> "Build APK" -> wait ~4 min (or click "Run workflow").
3. Open the finished run -> download **WiFiFTP-apk** -> unzip -> install `app-release.apk` on your phone (allow "install unknown apps").

## Or with Android Studio
Open this folder, let it sync, then Build > Build APK(s).

## Use
Phone and PC on the same Wi-Fi (or phone hotspot). Tap START, then type the shown address (e.g. ftp://192.168.1.5:2121) into Windows File Explorer's address bar.
